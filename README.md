# photon-team10-fall2026
Team 10's developed software for the Photon Laser Tag system.
Developed in Fall 2026.

To run the program, run the install file by navigating to its directory and running "./install.sh" as a root user, or by running "sudo ./install.sh".
Once the installer is done installing the program, it can be run from any directory by simply typing "photon" into the terminal.
